# Deploy

Runbook de deploy do projeto. Este arquivo é o **esqueleto**: ao adotar o pipeline, copiar a
seção "Runbook" de `.ai/structure/templates/deploy-scripts-template.md`, preencher com os dados
reais e adicionar os scripts `deploy-remote.sh` e `update-remote.sh` desta pasta.

Regras: `.ai/structure/rules/deploy.md`. Workflow: `.ai/structure/templates/deploy-workflow-template.md`.
